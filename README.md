# 제주, 우리 넷의 가을

제주 가족여행 일정과 장소를 날짜별로 정리하는 모바일 웹앱입니다.

지도 상단에서 제주 장소를 검색하고 **코스 담기**를 누르면 선택한 날짜의 동선에 추가됩니다. 검색해 추가한 장소는 **내가 찾은 곳** 목록에도 남습니다.

앱 주소: https://hkejys9654-tech.github.io/jeju-our-autumn/

휴대폰 브라우저에서 주소를 열고 홈 화면에 추가하면 아이콘으로 실행할 수 있습니다.

일정 변경 내용은 사용 중인 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지 않습니다.

카카오 지도를 사용하려면 [카카오 디벨로퍼스](https://developers.kakao.com/)의 JavaScript SDK 도메인에 `https://hkejys9654-tech.github.io`를 등록해야 합니다. 등록되지 않아도 앱의 간단 지도가 표시됩니다.
